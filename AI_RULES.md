# Nágila Hadad - AI Rules & Standards

Este arquivo contém as diretrizes invioláveis para o desenvolvimento e manutenção do projeto. A IA deve ler este arquivo antes de realizar qualquer alteração.

## 🛑 REGRAS CRÍTICAS (NÃO TOCAR)

1. **ESTABILIDADE DO PLAYER & HERO**: 
   - NÃO modificar o **Player de Vídeo** (vittalix-player.js e estilos relacionados).
   - NÃO modificar o **Hero / Header / Topo** de nenhuma página.

2. **GALERIA & PORTFÓLIO (HOMOLOGADOS)**:
   - NÃO alterar `galeria-videos.html` ou `portfolio-completo.html`. 
   - O design das setas orgânicas e o Cinema Full Screen estão homologados.

3. **PRESERVAÇÃO DO FUNCIONAMENTO**:
   - NÃO alterar nada que já esteja funcionando perfeitamente.

4. **ISOLAMENTO DE VERSÕES (MINIMALISTA VS RED)**:
   - Se o trabalho for no **Modo Minimalista**, NÃO tocar em arquivos da versão **Red**.
   - Se o trabalho for no **Modo Red**, NÃO tocar em arquivos da versão **Minimalista**.
   - Evitar contaminação de CSS entre as versões.
